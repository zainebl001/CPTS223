CPTS223 MA3: Sorting Algorithms
Performance analysis
1.
Quick sort was the fastest overall with a 1.1 ms average. Heap and Shell next, followed by insertion sort being the longest with an average of 54ms.

2.
Quick sort is the most efficent because it used a divide and conquer approach. Shell sort gets good response times because it uses a gap sequence. Heap is slower because of repeated overhead with heapify. Insertion is the slowest because of the O(n^2) time complexity which impacts at large sample sizes.

3.
I used the halving sequence because it provides good performance while also being simple saving me time for minimal performace loss.
